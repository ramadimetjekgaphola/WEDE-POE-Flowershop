# WEDE-POE-Flowershop website
SEO ,Search Engine Optimization is a practice of optimizing a website to rank higher on search engines like google. Its purpose is to increase visibility, drive traffic and ensure search engines can correctly crawl and index the site.

SEO practices on UX and performance:
SEO improves UX by enforcing fast load times, mobile responsiveness, and clear navigation. Practices like image optimization, lazy loading, and semantic HTML reduce bounce rate and improve Core Web Vitals, which makes the site faster and easier to use.

Benefits of implementing SEO:
Implementing SEO increases organic visibility, builds trust and credibility, and improves conversion rates. For my flower shop, it helps potential customers find products like bouquets when searching locally, without paying for ads.

HTML: Used semantic tags (header, nav, main, section), alt attributes on all images, proper heading hierarchy (h1-h3), and created robots.txt and sitemap.xml.
CSS: Minified CSS, used responsive design with media queries, and avoided render-blocking by optimizing layout.
JavaScript: Added lazy-loading for gallery images, lightbox functionality with keyboard accessibility, and form validation to improve UX without hurting crawlability; also added _headers for security.

Meta elements are hidden tags in the head that tell Google and the browser about our website. They help with SEO and how our site looks on Google and social media.Examples I used:
<title>Bloom & Blossom Flower Shop</title> .
<meta name="description" content="Affordable fresh flowers"> - shows as the small text under the link on Google.
<meta name="viewport" content="width=device-width, initial-scale=1.0"> - makes the site look good on phones.
